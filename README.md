# Global Olympic Sports Performance Analysis

A Tableau project that explores Olympic athlete-event data.

## Objective
To understand medal distribution, participation by country (NOC code) and participation by sport using data visualisation.

## Visualizations
1. Medal Analysis
2. Olympic Participation by Country
3. Sports Participation

## Dashboard and Story
The three charts are combined into one dashboard and presented as a Tableau story.

## Tools Used
Tableau, CSV dataset, GitHub

## Dataset
athlete_events.csv (Kaggle: 120 Years of Olympic History)

Note: counts show participation records, not unique athletes. NOC is a country code, not a country name.
