Global Olympic Sports Performance Analysis

A Tableau project on Olympic medals, countries and sports

About the Project

This project analyzes Olympic athlete data using Tableau. It shows medal distribution, participation by country (NOC code), and participation across sports through a dashboard and a story.

Visualizations

  • Medal Analysis
  • Olympic Participation by Country
  • Sports Participation
